# Vocowder

Вокодер для Zoom MS-70CDR в формате `.ZDL`: до 64 полос, левый вход — модулятор, правый — носитель, есть шум и freeze. Готовится новая версия.

Channel vocoder for Zoom MS-70CDR (`.ZDL`): up to 64 bands, IN L modulator, IN R carrier, noise and freeze. A new version is being prepared.
